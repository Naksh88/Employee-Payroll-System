EMPLOYEE PAYROLL SYSTEM
# PROBLEM STATEMENT

Managing employee records and salary calculations manually can be time-consuming and may lead to errors. The Employee Payroll System is developed to provide a simple command-line solution for managing employee information and payroll operations.

The system allows users to add, view, update, delete, and search employee records. It supports different employee types, including Full-Time Employees, Managers, and Interns, and calculates their gross salary, deductions, and net salary based on the defined payroll rules.

The application also provides payslip generation, department-wise payroll summaries, and employee sorting based on net salary. Employee records are stored in a file so that the data can be retained between program executions.

# PROJECT GOAL

The main goal of this project is to develop a reliable and easy-to-use payroll management system while demonstrating core Java concepts such as:

Object-Oriented Programming
Inheritance
Polymorphism
Collections
File Handling
Input Validation
Exception Handling
